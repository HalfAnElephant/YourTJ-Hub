# Working with external decisions

The authoritative decision system is [external](<https://github.com/YourTongji/YourTJ-Hub/blob/dev/AGENTS.md>). Do not create a parallel MADR record in this repository.

1. Read the authoritative record and preserve its stable identifier in the implementing Spec, change, or review.
2. Follow that system's status, approval, ownership, and supersession rules.
3. Keep repository-specific proof as links from the authoritative record when possible.
4. Ask before changing the configured source of truth or connecting an external system.
